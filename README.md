# The Public House

A responsive React + Vite guide to UK pub history, room-name etymology and architecture.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Features an interactive five-period timeline, five-room glossary, architectural field guide, four-nation overview and linked reading room. The pub illustration and architectural panels are original SVG/CSS artwork; no external images are required. Google Fonts are optional, with local serif and sans-serif fallbacks. Historical sources are linked in the reading room. Examples illustrate regional variety rather than an exhaustive inventory.
